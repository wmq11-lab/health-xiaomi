# 云朵收容所 · 健康监控应用

一个温柔的移动端健康监控应用，接入小米运动健康真实数据，用云朵语言呈现你的身体状态。

## 功能

- **今日**：睡眠、静息心率、步数、心情便签、健康行动
- **个人基线**：30 天有效记录、常用范围、今天偏离项
- **身体变化侦探**：通过上下文问题给出相关线索
- **相谈**：AI 便签式对话，引用真实同步数据
- **呼吸**：4 秒吸气、4 秒停留、6 秒呼气的 60 秒练习
- **周记**：手写信式周报，基于真实数据趋势
- **安全分诊**：排查胸痛、呼吸困难等立即风险

## 技术架构

```
小米手环/手表 → 小米运动健康 App → 华米(Huami)云 API
                                        ↓
                            Node.js 后端 (server.js)
                                        ↓
                         前端 data-sync.js → app.js
```

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置小米账号

```bash
cp .env.example .env
```

编辑 `.env`，填写你的小米账号：

```
XIAOMI_USERNAME=你的手机号或邮箱
XIAOMI_PASSWORD=你的密码
XIAOMI_REGION=cn
PORT=3000
```

### 3. 启动

```bash
npm start
```

浏览器打开 `http://localhost:3000`

> 未配置账号时，应用会自动回退到演示数据，所有功能仍可正常体验。

## 数据来源

通过华米（Huami）云 API 拉取以下数据：

| 数据类型 | API 端点 |
|---------|---------|
| 睡眠 | `/api/health/sleep` |
| 心率 | `/api/health/heart-rate` |
| 步数/运动 | `/api/health/activity` |
| 体重/体成分 | `/api/health/weight` |
| 全部聚合 | `/api/health` |
