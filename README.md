# 云朵收容所 · Android UI 原型

这是一个不依赖构建工具的高保真移动端交互原型，用浏览器直接打开 `index.html` 即可。

## 页面

- 今日：云层状态、睡眠、静息心率、心情便签、健康行动。
- 个人基线：展示 28 天有效记录、常用范围，以及今天偏离常用范围的项目。
- 身体变化侦探：通过 2～3 个上下文问题给出相关线索，但不把相关性说成因果。
- 相谈：AI 便签式对话、数据引用、风险提示。
- 呼吸：4 秒吸气、4 秒停留、6 秒呼气的 60 秒练习。
- 周记：手写信式周报、趋势、星光收藏、数据来源。
- 安全分诊：先排查胸痛、呼吸困难、晕厥、卒中征象等立即风险，再给出就医或继续观察建议。

## 视觉方向

- 关键词：云朵观测站、纸雕水彩、治愈微卡通、低饱和、清楚但不冷硬。
- 主色：奶白 `#FFFAF0`、雾蓝 `#CFE2E7`、薄荷 `#C7DFCE`、燕麦 `#F8F0DF`。
- 风险色只用于真正的红旗症状和危急提示，不用红色装饰健康状态。

## 正式安卓实现

建议采用 Kotlin + Jetpack Compose。原型中的云朵由 CSS 形状和 SVG 构成，迁移时可改为 Compose `Canvas` 或矢量 drawable；图标和 Logo 已经是可编辑 SVG。

Health Connect 需要逐项申请数据权限，并在界面上展示同步时间、缺失数据和数据来源。小米运动健康是否向 Health Connect 写入某项数据，必须以目标设备和地区真机验证结果为准。

原型中的个人基线、上下文关联和安全分诊均为交互演示，不是医学算法。正式产品应由确定性规则处理红旗症状，并让大模型只负责组织语言，不能由模型决定是否存在急症。
